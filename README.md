# Github-YFF-oppg
En yff oppgave til å lære seg om Github

Det jeg har endret til nå er selve README-filen, og en ZIPPET nettside fil(er)


Med dette prosjektet har jeg lært hvordan jeg bruker GitHub og hva det feks kan bli brukt til.

Mitt GitHub-bruk;
Jeg har laget en GitHub konto
  Så et repository under den kontoen
    Derved ble det lagdt til filer til denne repositoryen
    så har jeg redigert litt i README-filen

Brukt GitHub Desktop til Clone / Push
  Lærte hva de ble brukt til


Det jeg har lært;

GitHub kan bli brukt til å legge ut egene prosjekter for andre - dette er som at andre kan se på dem og komme med forslag, få egen inspiration, legge det ut til andre, legge ut 'maler' - kort sagt er GitHub der man deler sine prosjekter for å hjelpe communityen / på en måte få hjelp. Mange youtube-tutorials bruker å ha en GitHub link, der man kan finne hele prosjektet - det er for hvis du sitter med et problem / lyst å ha det ferdige prosjektet / bygge videre / osv..

GitHub er ganske lett å bruke.


Clone brukes til å lage en kopi av et prosjekt av ditt valg sånn at man kan skifte, fikse eller fjerne tinger fra prosjektet uten å skade den originale. Dette gir STOR mulighet til å 'leke' seg rundt uten å måtte tenke på skaden på den originale - også kan man oppdatere den originale med kopien, som at den originale for samme 'data' som kopien- til dette bruker vi PUsh

som skrevet, blir Push brukt til å dytte endringene som har blitt gjort på kopien til den originale - dette gjør det som at det er veldig lett å endre prosjektet veldig lett, og oppdatere det for massene.
